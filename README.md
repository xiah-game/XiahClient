# XiahClient (新侠道 - 游戏客户端主体)

## 项目简介
XiahClient 是玩家最终下载并运行的《新侠道》游戏客户端程序。它高度依赖 `XiahGameEngine` 提供的渲染与数学底层能力，主要负责客户端侧的业务逻辑串联，包括与服务端的网络报文交互、玩家鼠标键盘控制、界面操作以及实体模型的调度显示。

## 有啥用 (核心功能)
- **网络交互与状态同步**: 发送移动、攻击、技能请求，并解析服务端下发的 0x3B (角色信息)、0x40 (战斗与动作)、0x42 (物品) 等海量游戏协议。
- **主循环控制器**: 负责帧率更新、动画帧插值混合 (Interpolation)、以及 CPU 与 GPU 之间的资源分配调度。
- **场景与实体管理**: 根据网络视野 (AOI) 动态加载或卸载场景地块资源，创建视野内的玩家、NPC 及怪物 3D 模型实体。
- **游戏逻辑呈现**: 展现登录界面、角色创建、人物属性展示、技能快捷栏响应以及背包道具的拖拽与使用等 UI 行为。

## 编译依赖
- **操作系统**: Windows
- **开发工具**: Visual Studio
- **核心引擎依赖**: 必须提前编译好 **XiahGameEngine** 项目，确保拥有其最新生成的 `.lib` 文件和头文件。
- **第三方库**: DirectX SDK, FMOD 等（要求与引擎侧配置保持完全一致）。

## 如何编译
1. 确保同级目录下的 `XiahGameEngine` 已经成功编译通过。
2. 打开客户端项目的解决方案文件 (`.sln`)。
3. 检查项目属性面板：
   - **C/C++ -> 常规 -> 附加包含目录**：确保能正确找到 `XiahGameEngine` 暴露出的头文件。
   - **链接器 -> 常规 -> 附加库目录**：确保路径指向引擎库刚才的输出目录。
4. 根据需要选择 `Release` 模式（推荐用于测试流畅度）或 `Debug` 模式（方便断点排查崩溃问题）。
5. 点击生成。
6. 编译成功后，将生成的客户端主程序 `.exe` 拖入包含游戏资源目录（如 `Data/`, `UI/`, `Bgm/`）的纯净客户端目录下双击运行。
